# germanbonacchi.com

Personal portfolio of **Germán Bonacchi**, Technical Lead for VTEX and ecommerce architecture.

## Stack

- Next.js (App Router)
- TypeScript (strict)
- CSS Modules + design tokens
- Vercel Analytics + Speed Insights
- Google Analytics 4 (gtag)
- Contact via WhatsApp / LinkedIn / email deep links

## Scripts

```bash
yarn
yarn dev
yarn lint
yarn typecheck
yarn build
```

## Environment

Copy `.env.example` to `.env.local` and set:

- `NEXT_PUBLIC_SITE_URL`
- `NEXT_PUBLIC_GA_MEASUREMENT_ID`

## Content

Typed content lives in `/content` (`experience`, `projects`, `technologies`, `ui`, `site`).
